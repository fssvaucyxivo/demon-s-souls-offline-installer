## About

Demon's Souls is the critically acclaimed FromSoftware action RPG that started the Soulsborne genre. Set in the cursed kingdom of Boletaria, players battle powerful demons, collect souls, and face punishing but fair combat. The 2020 remake by Bluepoint Games rebuilt the visuals completely while preserving the original gameplay design that defined a generation of games.
